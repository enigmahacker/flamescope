## Project Name
Flamescope

## High-Level Project Summary
Flamescope is a web dashboard that turns decades of NASA microgravity fire experiments into answers crews can use on the Moon and Mars. It collects flame-spread runs from NASA technical reports and Physical Sciences Informatics (PSI) datasets into one table, one row per experiment run. It then summarizes them as insight cards, ranks them against lunar and Martian cabin atmospheres, and answers questions in plain English. Every claim links to the run or source passage it came from, and the system refuses when the sources don't support an answer. As crews prepare to live in oxygen-enriched, low-pressure habitats, Flamescope makes the existing fire evidence easy to find, compare, and trust. It also shows clearly where that evidence runs out.

## Detailed Project Description
**What it does**
- **Ask:** type a question and get matching source passages, matching runs, and a short answer with citations. Off-topic or unsupported questions get a refusal, not a guess.
- **Insights:** cards summarizing what the data says for habitats, transport, and long-duration missions. Each card is tagged with its evidence status.
- **Rank:** runs ordered by how close their oxygen and pressure are to the Moon or Mars cabin target, next to an oxygen-vs-pressure chart. Only runs whose numbers a second person has verified enter the ranking.
- **Runs, Atmospheres, Sources, Evaluation:** the full tables, data-quality flags, licenses, and retrieval scores.

**How it works**
An offline Python pipeline:
1. Fetches every source listed in a manifest from the NASA NTRS and PSI APIs.
2. Extracts run parameters from paper text and PSI experiment tables, converting units to kPa, mm/s, and m/s while keeping the as-reported values.
3. Validates required fields and verification status. Runs missing a required field are excluded, not ranked low.
4. Builds a passage corpus and a BM25 search index.
5. Uses a Groq-hosted large language model to answer questions from retrieved records only.

A validator drops any answer containing a number that isn't in a cited run. The site is static, runs search in the browser, and ships no API key. Visitors can optionally paste their own Groq key for live answers.

**Benefits**
- One place to compare microgravity flame-spread evidence.
- Answers traceable to their sources.
- Data gaps made explicit. For example: no tested run matches the lunar 34% O2 / 56.537 kPa atmosphere, and the corpus has no partial-gravity runs yet.

**What we hope to achieve**
A trusted, growing evidence base that mission planners and crew trainers can query when setting cabin atmospheres and choosing materials, and a clear list of the experiments still needed.

**Tools**
Python (standard library, sentence-transformers), HTML, CSS, and JavaScript (no framework), the Groq API, GitHub Pages and GitHub Actions, the NASA NTRS API, and the NASA PSI repository API.
