Flamescope

How fire behaves off Earth, from decades of microgravity experiments: summarized, ranked and interpreted for crews on the Moon and Mars. Every claim links to a run or a source passage.

Live AI mode (optional): use your own Groq API key

Flamescope never stores a key in this site. A key you enter stays in this browser tab only (session storage) and is sent only to api.groq.com. Answers are checked here: any number that is not in a cited run or atmosphere target is rejected.

Retrieval runs in your browser over a fixed BM25 index. SI answers were generated offline with a Groq-hosted LLM, grounded in the retrieved records, and kept only if every number matches the run table.
